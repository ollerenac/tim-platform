INCIDENT REPORT IR-2026-0087
MireRAT Intrusion at a Maritime Logistics Provider
Classification: TLP:AMBER (sanitized excerpt for TLP:CLEAR distribution)

1. OVERVIEW
This report documents a fourteen-month intrusion at a maritime logistics provider,
attributed to the operators of MireRAT. The intrusion was discovered during a retro-hunt
initiated after publication of a single file hash by an external research team, underscoring
the value of shared indicators even for low-and-slow campaigns.

2. INTRUSION NARRATIVE
Initial access predates available logging. The earliest confirmed artifact is a MireRAT
loader (SHA-1: 35ce6f52efd127a6d562f2300531656712904bd4) staged in a user profile directory in March 2025. The core
implant (SHA-256: 84d60dd008e7b5b40191bc0919401ed5ed5756b1f46da3febbafe0712e548c03) communicated once daily with rotating relay infrastructure,
blending into business-hours traffic. Collection focused on cargo manifests, vessel
schedules, and correspondence with port authorities.

3. INFRASTRUCTURE
Relay addresses observed across the intrusion window:
  192.0.2.33
  192.0.2.34
  203.0.113.88

Rendezvous domains:
  harbor-manifest.example
  tide-tables.example

A single tasking URL was recovered from memory: https://harbor-manifest.example/api/v2/sync

4. LESSONS LEARNED
Threshold-based network detections did not fire at any point during the intrusion. The
discovery pathway ran entirely through file-based retro-hunting. Organizations in targeted
logistics sectors should treat artifact hunting as a first-class detection discipline
rather than an incident response afterthought.
